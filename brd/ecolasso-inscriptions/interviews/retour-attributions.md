# Quatorze paroles sans voix — à attribuer

> Quatorze sources du dossier portent une parole dont je ne sais pas qui l'a dite : la réponse est arrivée sans prénom. Je n'ai pas voulu deviner, parce qu'une attribution fausse se propage dans tout ce qui s'appuie sur elle — c'est déjà arrivé une fois sur ce dossier, et il a fallu découper une source en deux et réattribuer quatre citations.
>
> **Quatre d'entre elles portent des faits d'organisation** et n'ont pas la même portée selon qu'elles viennent du bureau, de la direction ou d'un parent. Elles sont marquées ⚠.

| Source | La parole | Qui ? |
|---|---|---|
| SRC-025 | ⚠ « Le comptable ne fait pas partie de l'association » | |
| SRC-029 | ⚠ « C'est jamais arrivé » — à propos de l'urgence médicale | |
| SRC-031 | ⚠ « Le dossier est récupéré par un des enseignants dans le bureau. L'association n'est responsable qu'aux heures de présence de l'enfant » | |
| SRC-032 | ⚠ « Tant qu'il y a des élèves, le bureau reste ouvert » | |
| SRC-038 | « On peut aussi considérer le nombre de dossiers avec des données manquantes » | |
| SRC-040 | « Oui je les retiens » — rétention de cinq besoins candidats | |
| SRC-041 | « Si on a le pouvoir de contacter les parents on fait des relances » | |
| SRC-042 | « C'est les membres du bureau » — qui fait les relances | |
| SRC-043 | « Le règlement va être réadapté, plus de paiement en chèque » | |
| SRC-044 | « Aujourd'hui c'est échelonné entre avril et juin » | |
| SRC-045 | Décision de réécrire l'article 7 avec l'exception | |
| SRC-046 | « Toutes les familles peuvent corriger seules » | |

*Les deux dernières lignes manquantes — SRC-001 (le cadrage) et SRC-003 (le dossier d'inscription, qui est un document) — ne relèvent pas d'une parole individuelle.*

**Le plus simple pour l'avenir : préfixer chaque réponse du prénom de qui parle.** Une convention établie une fois vaut mieux qu'une question d'attribution par tour.
