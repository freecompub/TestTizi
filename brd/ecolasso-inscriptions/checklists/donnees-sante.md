# Relecture — Données de santé — EcolAsso — Inscriptions et réinscriptions

Ces points testent la **qualité des exigences**, pas le code. Ils se cochent par un **relecteur nommé**, jamais par l'agent :

- `- [x] CL-… — Prénom Nom` : le point est satisfait ;
- `- [~] CL-… — Prénom Nom : raison` : le point ne s'applique pas, avec sa raison ;
- un point non satisfait reste vide, et devient une zone d'ombre ou une correction du document.

Les points non traités bloquent la gouvernance du document.

- [ ] CL-SAN-01 Les valeurs cliniques (unités, bornes, arrondis) sont-elles spécifiées sans ambiguïté ?
- [ ] CL-SAN-02 Le comportement face à une valeur hors bornes ou incohérente est-il exigé ?
- [ ] CL-SAN-03 Les textes à portée clinique sont-ils identifiés pour une validation par un professionnel de santé ?
- [ ] CL-SAN-04 Les exigences disent-elles ce qui se passe si une donnée de santé est manquante ou ancienne ?
- [ ] CL-SAN-05 Les règles d'hébergement et de consentement applicables sont-elles reprises en exigences ?
