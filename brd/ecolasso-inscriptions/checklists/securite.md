# Relecture — Sécurité — EcolAsso — Inscriptions et réinscriptions

Ces points testent la **qualité des exigences**, pas le code. Ils se cochent par un **relecteur nommé**, jamais par l'agent :

- `- [x] CL-… — Prénom Nom` : le point est satisfait ;
- `- [~] CL-… — Prénom Nom : raison` : le point ne s'applique pas, avec sa raison ;
- un point non satisfait reste vide, et devient une zone d'ombre ou une correction du document.

Les points non traités bloquent la gouvernance du document.

- [ ] CL-SEC-01 Les données manipulées sont-elles toutes classées (personnelle, santé, confidentielle, publique) ?
- [ ] CL-SEC-02 Pour chaque action sensible, les exigences disent-elles qui a le droit de la faire ?
- [ ] CL-SEC-03 Les exigences précisent-elles ce qui se passe après un échec d'authentification ou une session expirée ?
- [ ] CL-SEC-04 Les données sensibles exclues des journaux et des messages d'erreur sont-elles nommées ?
- [ ] CL-SEC-05 Les durées de conservation et la suppression des données sont-elles exigées ?
- [ ] CL-SEC-06 Les exigences couvrent-elles la traçabilité des accès aux données de santé ?
