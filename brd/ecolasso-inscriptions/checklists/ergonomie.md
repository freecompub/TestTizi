# Relecture — Ergonomie — EcolAsso — Inscriptions et réinscriptions

Ces points testent la **qualité des exigences**, pas le code. Ils se cochent par un **relecteur nommé**, jamais par l'agent :

- `- [x] CL-… — Prénom Nom` : le point est satisfait ;
- `- [~] CL-… — Prénom Nom : raison` : le point ne s'applique pas, avec sa raison ;
- un point non satisfait reste vide, et devient une zone d'ombre ou une correction du document.

Les points non traités bloquent la gouvernance du document.

- [ ] CL-ERG-01 Chaque message d'erreur exigé dit-il quoi faire pour corriger ?
- [ ] CL-ERG-02 Les états vides, de chargement et hors connexion sont-ils spécifiés ?
- [ ] CL-ERG-03 Les contraintes d'environnement d'usage (une main, interruptions, lumière) se traduisent-elles en exigences ?
- [ ] CL-ERG-04 Les termes affichés sont-ils ceux du glossaire, sans synonymes ?
- [ ] CL-ERG-05 Les confirmations avant une action irréversible sont-elles exigées ?
