# SRC-004 — Traitement d'un dossier au bureau

- **Type** : entretien — **preuve de première main**
- **Date** : 2026-10-27
- **Voix entendue** : SH-03 (Tom, membre du bureau, qui traite lui-même les dossiers)
- **Présents** : SH-01, SH-02, SH-03

## Le processus décrit

1. Le parent dépose le dossier papier au bureau.
2. Un membre du bureau le prend.
3. Il vérifie les données saisies et le paiement.
4. Si tout est correct : il **doit** envoyer un message WhatsApp disant que c'est validé.
5. Sinon : il envoie un message listant les données manquantes, et le parent **doit revenir au bureau**
   pour corriger.

## Un fichier Excel, jamais mentionné jusqu'ici

Quand un parent vient dire qu'il n'a pas eu de réponse, Tom **cherche dans un fichier Excel** si le
dossier est « ok ou non ».

Ce que cela établit :
- Il existe un **support de suivi** hors du papier. Le statut d'un dossier y est consultable.
- Les informations des dossiers papier font donc l'objet d'une **seconde saisie**, par le bureau.
  La ressaisie annuelle n'est pas seulement celle des 150 familles : le bureau recopie aussi.

Ce que cela n'établit pas (ZO-045) : ce que le fichier contient exactement, qui le remplit et à quel
moment, où il est rangé, qui peut l'ouvrir, et s'il conserve les données des années précédentes.
